# Glossary

Domain vocabulary, mostly Polish (product's primary language). Grows as
needed — add a term when it's used in code/docs without an obvious meaning.

| Term | Meaning |
| --- | --- |
| Kaucja | Deposit — Poland's deposit-refund packaging system (bottles, cans). |
| Kaucjomat / butelkomat | Reverse vending machine that accepts deposit packaging and refunds the deposit. |
| Punkt zwrotu | Return point — any place (machine, shop, other) accepting deposit packaging. |
| Status punktu | Return point status — see enum below. |
| Dostępny | Status: available, accepting returns. |
| Zapełniony | Status: full, machine can't accept more. |
| Nieczynny | Status: closed. |
| Awaria | Status: technical fault. |
| Brak informacji | Status: no current info available. |
| Do weryfikacji | Status: reported but not yet community-verified. |
| Zgłoszenie | Report/submission — a user-submitted new point or status update. |
| Potwierdzenie | Confirmation — community upvote/verification of a report or status. |
| KaucjoMapa | Working/product name, may be renamed before launch — see `README.md`. |
